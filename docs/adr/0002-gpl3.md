# ADR 0002 — GPL-3.0-or-later

- **Status:** accepted
- **Date:** 2026-10-11

## Context

Since no libobs code is used (ADR-0001), the licence choice is genuinely free rather than inherited.
The project is open source by intent. Dependency constraints:

- **Qt 6 is LGPLv3** — this rules out GPL-2.0-*only*. A GPL route must be v3 or "v2-or-later".
- **FFmpeg is LGPLv2.1+ by default but GPL when built with x264/x265**, and Arch's `ffmpeg` is the
  GPL build. A permissive project shipping bundles (Flatpak, MSI, DMG) would need to assemble its own
  LGPL FFmpeg without x264.
- **VST3's SDK is dual GPLv3 / proprietary.** GPLv3 gets it free; permissive needs a Steinberg
  agreement. (CLAP is MIT, which is why CLAP is first-class regardless.)
- `libdatachannel` and SRT are MPL-2.0, Cap'n Proto MIT, Slang Apache-2.0 — compatible with anything.

## Decision

**GPL-3.0-or-later**, with `REUSE.toml` and SPDX headers from the first commit.

## Rejected alternatives

**Apache-2.0.** Maximum adoption, explicit patent grant, trademark protection (better than MIT for a
named project). Rejected because this market has a demonstrated predator: Streamlabs built a
commercial product on OBS, and copyleft is the only reason any of that work came back. Also creates
real friction with GPL FFmpeg/x264 bundles and with VST3.

**MPL-2.0.** File-level copyleft — modified Libertas files stay open while proprietary code may link.
A reasonable middle path, explicitly GPL-compatible downstream. Rejected as weaker protection against
a well-funded fork, which is the specific risk we care about.

**Split Apache-2.0 `libs/` + GPL-3.0+ `apps/`.** Attractive — the document model, IPC, RHI and theme
follower would be reusable by other Wayland tooling. Rejected for now as dual-license bookkeeping
overhead on a solo project. Revisitable: moving `libs/` to Apache later is a relicensing of code we
author, so this door stays open while contributions remain in-house.

**AGPLv3.** Only relevant if we ran a hosted multistreaming service, which we explicitly will not
(see the plan's multistreaming section). It also deters corporate contributors.

## Consequences

- Proprietary *native in-process* plugins become legally murky — irrelevant, since ADR-0004 rejects
  that model on stability grounds anyway. Extensions are shaders, Wasm, or separate processes, so
  extension authors may licence their work however they wish.
- GPLv3 blocks Apple App Store distribution. macOS ships as a notarized DMG; no impact.
- **Relicensing asymmetry:** free while sole-authored, requires unanimous contributor consent
  afterwards. Decide on a CLA *before* merging the first outside patch if that door should stay open.
